# alenaodeon.com

Source for [alenaodeon.com](https://alenaodeon.com), the personal site of Alena Odeon.

## Development

```bash
npm install
npm run dev
```

The site is at http://localhost:4321. `npm run build` writes the static output to `dist/`.

Content lives as Markdown in `src/content/` (experience, projects, blog). Site-wide settings are in `src/config.ts`.
